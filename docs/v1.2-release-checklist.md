# Organizador IA v1.2 — Checklist técnico

## Objetivo

Melhorar observabilidade, diagnóstico e distribuição sem alterar o núcleo determinístico de organização de arquivos.

## Relatório final

O resultado de uma execução deve deixar claro:

- arquivos processados;
- arquivos ignorados e motivo resumido;
- arquivos que falharam;
- quantidade de resumos gerados;
- quantidade de itens recuperados do cache;
- duração da operação, quando disponível.

Nenhum relatório deve registrar chaves de API, tokens ou conteúdo sensível original.

## Diagnóstico de configuração

- indicar de forma clara quando a integração com IA está desabilitada;
- diferenciar ausência de configuração de erro de autenticação;
- não imprimir o valor de segredos;
- manter a organização local funcional quando a IA não estiver disponível.

## Cancelamento

- garantir que o cancelamento não deixe tarefas pendentes produzindo arquivos inesperadamente;
- preservar o estado consistente do cache;
- apresentar o cancelamento como resultado esperado, não como falha genérica.

## `--dry-run`

O modo de simulação deve permanecer sem efeitos colaterais:

- não mover arquivos;
- não criar relatórios persistentes;
- não alterar cache;
- não chamar a API de IA.

## Distribuição

Revisar o fluxo de build para Windows e Linux, verificando:

- dependências incluídas;
- arquivos necessários no executável;
- mensagens de erro quando um recurso estiver ausente;
- documentação reproduzível do processo de build.

## Testes mínimos

1. relatório com arquivos processados e ignorados;
2. falha individual sem interromper a execução inteira;
3. ausência de chave de API;
4. erro de API sem exposição do segredo;
5. cancelamento durante processamento;
6. `--dry-run` sem efeitos colaterais;
7. cache preservado após cancelamento;
8. caminho com caracteres especiais;
9. distribuição sem arquivo obrigatório.

## Critério de conclusão

A versão só deve ser marcada como `1.2.0` quando os testes cobrirem os cenários críticos e a documentação de distribuição estiver alinhada com o comportamento real do aplicativo.
